# JOIN-AND-KEY-
A hands-on SQL project focused on understanding relational database concepts, including Primary Keys, Foreign Keys, and different types of SQL JOINs. This project demonstrates how to combine data from multiple tables and retrieve meaningful information using MySQL.

Key Concepts:

Primary Key and Foreign Key
INNER JOIN
LEFT JOIN
RIGHT JOIN
Table relationships
Retrieving data from multiple tables
Tool Used: MySQL Workbench

Objective: To develop practical SQL skills and understand how relational databases connect and manage data.
